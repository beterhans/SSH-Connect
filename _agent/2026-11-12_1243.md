# Session: legacy SSH algorithm support (parity with iSAM_line_Check.py)

## Current Target
Make the MCP tool connect to old devices (Alcatel iSAM OLTs) that only offer
SHA-1 kex / ssh-rsa / ssh-dss host keys / CBC ciphers / hmac-sha1 — same
capability as the Python Netmiko script, for BOTH tool paths.

## Key Points / Problems
- Gap 1: `transport/ssh.rs` legacy list missing `kex::DH_GEX_SHA1`,
  `Algorithm::Dsa` (ssh-dss), and any SHA-1 MACs.
  russh 0.60 `Preferred::DEFAULT` mac list is SHA-2-only; comment at old
  line 65 ("default MAC order already ends with hmac-sha1") is stale.
- Gap 2: `tools/ssh_tools.rs` (ssh_connect/exec/sftp) used
  `client::Config::default()` = modern-only. Now reuses the legacy list via
  `crate::transport::ssh::legacy_compatible_preferred()` (made pub).
- Verified in russh 0.60.3 source: DH_GEX_SHA1 registered (kex/mod.rs),
  Algorithm::Dsa exists in forked ssh-key, mac::HMAC_SHA1 available.
  arcfour/RC4 not implemented in russh at all (out of scope, pre-2010 only).
- Python script's DSSKey.verify_ssh_sig→True hack: russh verifies properly,
  no bypass hook. If an iSAM emits broken DSA kex signatures it would fail —
  watch for that in real-world testing.

## Session 3 — live connect to 192.168.1.86 (a Mac used as a fake device)
- Added **session transcript log** (`src/transport/session_log.rs`): every byte
  TX/RX, escaped, timestamped → `~/.ssh-connect/logs/<session>.log`.
  Path returned by `connect` + `list_sessions`. Env: SSHCONNECT_SESSION_LOG=off,
  SSHCONNECT_SESSION_LOG_DIR. Secrets are NOT masked.
- **Bug found + fixed** (`src/transport/mod.rs::strip_ansi`): backspaces were
  dropped instead of applying erase semantics → zsh ZLE's `<char>^H<char>`
  redraw left a duplicated first char ("uuname -a"). Now a backspace followed by
  a printable char erases the previous char; a pager's `^H ^H` erase-in-place
  is still dropped so "--More--" survives for strip_pager.
  2 new unit tests; 27/27 pass.
- Mac needs a custom prompt regex (zsh pads the prompt to the 200-col PTY):
  `johnny@[\w.-]+ [^\r\n]*%` → commands dropped from 30 s timeout to ~10-60 ms.
- Auth ladder note: `ssh -G` lists default IdentityFiles, so key auth succeeds
  even with a wrong password; `use_agent:false` does NOT disable the key files.
- Driver `$HOME/Downloads/temp/mcp_drive.py` gained --key-path/--no-agent/--prompt
  and an interactive getpass prompt (the "pop-out window" equivalent).
- Regression: 27/27 unit, 4/4 E2E legacy, 5/5 matrix — all green.
- Docs: MCP_EXPLAINED.md (updated), LEGACY_SSH_TESTING.md, LEGACY_SSH_HANDOFF.md.

## Session 4 — opencode registration + two more real bugs
- **Registered the MCP server** in `~/.config/opencode/opencode.json`
  (`opencode mcp add ssh-connect --global --env SSHCONNECT_HOSTS=<...>/hosts.toml
  -- <release binary>`). Backup: opencode.json-01.old. Verified live: 38 tools
  appeared in the catalog, `list_hosts` returned the inventory.
- **Skills written** to `~/.config/opencode/skills/`:
  `ssh-connect/SKILL.md` (core usage) and `ssh-connect-legacy-devices/SKILL.md`
  (old iSAM/OLT playbook). Both picked up automatically.
- `hosts.toml` created (gitignored) with a `test-mac` entry.
- **Bug: prompt-redraw race.** A device that redraws its prompt while accepting
  the previous line puts prompt+echo on ONE line. A non-end-anchored regex
  matched it → read ended before the output arrived → the leftover was reported
  as the NEXT command's output ("uuname -a" style shift). Fixed in
  `read_until_prompt` + `run_command_inner`:
  - drain now loops until the device is quiet (was: one 50 ms chunk),
  - a prompt match is only accepted after a 150 ms settle read finds no more
    data (a redraw is followed by more data).
  Verified: 3 consecutive commands now each return their own output.
  **Lesson (now in both skills): prompt regexes MUST be end-anchored `\s*$`.**
- **Broker gotcha:** a second `ssh-connect` process becomes a PROXY and forwards
  to the running owner — so a stale owner silently serves OLD code. The MCP
  server process must be restarted after a rebuild (kill it; opencode respawns,
  or `/reload`).
- Final regression: 27/27 unit, 4/4 E2E legacy, 5/5 matrix, release binary
  verified against 192.168.1.86.
